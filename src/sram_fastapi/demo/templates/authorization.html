Authentication vs Authorization

Concept Description
Authentication Verifies who you are. SRAM handles this via OIDC.
Authorization Determines what you can access based on your attributes.

Implementation

Use the authorization dependencies in your routes:

from sram_fastapi.auth import require_entitlement, require_affiliation

@app.get("/admin")
async def admin_page(
    user = Depends(require_entitlement("urn:example:admin"))
):
    return {"message": "Welcome, admin!"}

@app.get("/staff")
async def staff_page(
    user = Depends(require_affiliation("staff@"))
):
    return {"message": "Welcome, staff!"}
